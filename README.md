# Pong Ultimate

Pong Ultimate is a modern remake of the classic Pong arcade game built with HTML, CSS, and JavaScript.

## Features

* Smooth and responsive gameplay
* Single-player mode against AI
* Score tracking system
* Clean and modern user interface
* Keyboard controls
* Lightweight and fast performance
* Playable directly in a web browser

## Controls

* W / S Keys: Move Left Paddle Up and Down
* Arrow Up / Arrow Down: Move Right Paddle Up and Down
* Space Bar: Start or Restart Game

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## About

This project recreates the classic Pong experience with modern web technologies. It is designed to be simple, fun, and accessible on desktop browsers without requiring any installation.
